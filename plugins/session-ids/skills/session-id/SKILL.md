# Get the current session's readable id

Every session gets a readable id at startup — two random words joined by a
dash, adjective first, noun second (e.g. `brave-otter`) — generated by this
plugin's SessionStart hook.

## How to find it

1. **Session context (preferred).** The hook injected a line like
   `This session's readable id is "brave-otter" (session_id: <uuid>)` at
   session start. If that context is still visible, use it directly — no
   commands needed.

2. **State file fallback.** If the context was lost (e.g. compaction), read
   the stored record:

   ```bash
   bash "${CLAUDE_PLUGIN_ROOT}/scripts/session-info.sh"
   ```

   This prints the latest session record as JSON; the id is the
   `readable_id` field. Records live in
   `${CLAUDE_SESSION_IDS_DIR:-$HOME/.claude/session-ids}/<session_id>.json`
   — if you know the session UUID, pass it as the first argument for an
   exact match instead of relying on `latest`.

## Using the id

- Report it to the user plainly: the id, and that it was generated at
  session start.
- When assigning work in a `_projects/` todo.md, link it as
  `[assignee:<readable-id>]`.
