# projects

A Claude Code plugin that manages a `_projects/` folder — a lightweight,
file-based project workspace.

## What it manages

```
_projects/
  README.md                          # conventions for the folder (written by init)
  CLAUDE.md                          # symlink -> README.md, so Claude sessions load the rules
  YYYY-MM-DD--<project-name>/        # one folder per project
    todo.md                          # checkbox todos, @priority mentions, [assignee:<id>] links
    README.md                        # small notes — kept under 256 lines
    ...                              # any ad-hoc project files
```

- **Priorities** in `todo.md` are @-mentions: `@high`, `@medium`, `@low`.
- **Assignees** are linked by readable id (`[assignee:brave-otter]`) — ids are
  the adjective-noun session ids generated by the companion `session-ids` plugin.
- Each project `README.md` holds random small notes and must stay **under 256
  lines**; the top-level `_projects/README.md` documents that limit.

## Skills

| Skill | Purpose |
|-------|---------|
| `init-projects` | Create `_projects/` with its README and the `CLAUDE.md` symlink. |
| `new-project` | Scaffold `_projects/YYYY-MM-DD--<name>/` with `todo.md` and `README.md`. |
| `project-todos` | Add / complete / reprioritize / assign tasks in a project's `todo.md`. |

## Scripts

- `scripts/init-projects.sh [base-dir]` — idempotent `_projects/` bootstrap.
- `scripts/new-project.sh <name> [base-dir]` — scaffold a project folder.
- `scripts/check-readmes.sh [base-dir]` — flag project READMEs at/over 256 lines.
