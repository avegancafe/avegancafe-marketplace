# Create a new project

Scaffold a project folder in `_projects/`.

## Steps

1. If `_projects/` doesn't exist yet (with its README.md and CLAUDE.md
   symlink), run the `init-projects` skill first.

2. Pick a short, descriptive project name. Then run:

   ```bash
   bash "${CLAUDE_PLUGIN_ROOT}/scripts/new-project.sh" "<project name>" [base-dir]
   ```

   The script slugifies the name to kebab-case and creates
   `_projects/YYYY-MM-DD--<slug>/` (today's date) containing:

   - `todo.md` — seeded with the todo format header and one starter task.
   - `README.md` — for the project's random small notes. **Keep it under
     256 lines**; move longer content into separate files in the folder.

3. Fill in the initial `todo.md` tasks with the user if they described work
   to do, using the format from `_projects/README.md`:

   ```markdown
   - [ ] Task description @high [assignee:<id>]
   ```

   Priorities are `@high` / `@medium` / `@low`; assignees are linked by the
   readable session id (e.g. `[assignee:brave-otter]`) generated by the
   `session-ids` plugin.

## Notes

- Any ad-hoc files for the project (scripts, exports, drafts) belong inside
  the project folder — not at the `_projects/` root.
- Never rename an existing project folder's date prefix; it records when the
  project started.
